Verbindung

Die URL deines InnoSmith OS-Backends (ohne Trailing-Slash), z.B. https://tp.innosmith.ai oder http://localhost:8000.

Generiere den Key in InnoSmith OS unter Einstellungen → Integrationen → Browser-Extension. Er beginnt mit tpk_ und läuft nicht ab.

Cloudflare Access Optional

Falls dein Backend hinter Cloudflare Access geschützt ist (z.B. tp.innosmith.ai), benötigt die Extension einen Service Token, um sich zu authentifizieren.

Zu finden unter: Cloudflare Zero Trust → Access → Service Auth → Service Tokens.

Wird nur bei der Erstellung angezeigt — sicher aufbewahren.
